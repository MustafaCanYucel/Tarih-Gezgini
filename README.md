# 🏛️ Tarih Gezgini

Türkiye'nin tarihi bölgelerinde koşarak sorulara cevap verin!

## 🎮 Oyunu Oyna

**Web Versiyonu:** [Oyuna Başla](https://KULLANICI_ADINIZ.github.io/tarih-gezgini/)

## 📱 Mobil Uygulamalar

- **Android:** `TarihGezgini.apk` dosyasını indirin
- **iOS:** Xcode ile derleyin veya TestFlight kullanın

## 🎯 Özellikler

- ✅ 4 farklı tarihi bölge
- ✅ 16 eğitici tarih sorusu
- ✅ Her seviye için özel müzik
- ✅ 3D grafik (Three.js)
- ✅ Ses efektleri
- ✅ Başarı sertifikası
- ✅ Mobil uyumlu

## 📍 Seviyeler

1. **🎈 Kapadokya** - Peri bacaları ve sıcak hava balonları
2. **🏺 Mezopotamya** - Dicle nehri ve ziggurat'lar
3. **🏛️ Anadolu Uygarlıkları** - Antik tiyatrolar ve Lidya paraları
4. **🏘️ Eskişehir Odunpazarı** - Tarihi evler

## 🎵 Ses Dosyaları

Oyun için gerekli ses dosyaları `assets/sounds/` klasöründe bulunmaktadır:

- `bgSound1.mp3` - Kapadokya müziği
- `bgSound2.mp3` - Mezopotamya müziği
- `bgSound3.mp3` - Anadolu müziği
- `bgSound4.mp3` - Eskişehir müziği
- `coinSound.mp3` - Para toplama sesi
- `hitSound.mp3` - Engele çarpma sesi
- `correctAnswerSound.mp3` - Doğru cevap sesi
- `wrongAnswerSound.mp3` - Yanlış cevap sesi
- `gameOver.mp3` - Oyun bitti sesi
- `gameWin.mp3` - Oyun kazanıldı sesi

## 🎮 Kontroller

- **A** / **Sol Ok** - Sola git
- **D** / **Sağ Ok** - Sağa git
- **Fare** - Cevap seç

## 🛠️ Teknolojiler

- Three.js (3D grafik)
- HTML5 Canvas
- Web Audio API
- Vanilla JavaScript

## 📦 Kurulum

### Web Versiyonu
1. Dosyaları bir web sunucusunda barındırın
2. `index.html` veya `tarih-gezgini-final kopyası.html` dosyasını açın

### Android APK
1. `TarihGezgini.apk` dosyasını Android cihazınıza aktarın
2. APK'yı yükleyin ve oynayın

### iOS
1. Xcode'da `tarih-gezgini-mobile/platforms/ios/App.xcworkspace` dosyasını açın
2. Simulator veya gerçek cihazda çalıştırın
